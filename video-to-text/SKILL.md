# video-to-text — 小红书 / B站 / 小宇宙 转文字稿

把一条小红书、B站视频或小宇宙播客单集的口播内容，转成一份干净的 Markdown 文字稿。

这些平台的内容通常都没有可直接复制的字幕，文字稿要靠"下载视频/音频 → 语音识别"得到。这条链路坑很多（页面数据动态渲染、流地址有时效签名、huggingface.co 在大陆常被墙、Whisper 会在结尾产生重复幻觉、B站取流接口有风控），所以本 skill 把稳定可复现的部分固化在 `scripts/transcribe.py` 里，把需要判断的部分（校对术语错字、整理分段）留给你。

**执行准则（重要）**：这类请求直接把整个流程跑完、写好 Markdown 文件、再向用户汇报路径和摘要即可，**中途不要反复问用户**（不要问"要不要校对""用字幕还是 ASR""要不要打开文件"等）。仅在遇到真正的阻塞时才打断用户：`xsec_token` 过期、地区/会员限制取不到流、小宇宙付费/私密单集、链接无法识别。用户已了解整个流程，更希望"直接做完再通知"。

## 平台差异（决定文案怎么写）

| | 小红书 | B站 | 小宇宙 |
| --- | --- | --- | --- |
| 取元信息 | 解析页面 `window.__INITIAL_STATE__` | `web-interface/view` 接口 | 解析单集页 `__NEXT_DATA__`（Next.js SSR JSON） |
| 取音频 | 直链下载 mp4 → ffmpeg | `platform=html5` 的 playurl 取流（匿名可用） | 公网 CDN 直链 `media.xyzcdn.net/…m4a`（无需 token/签名） |
| 字幕 | 无，一律 ASR | 接口里有 CC/人工字幕时优先用；但播放器里的"AI字幕"是客户端实时生成、接口拿不到，所以**多数B站视频实际仍走 ASR** | 无（transcript 接口需登录），一律 ASR |
| 链接注意 | 从发现页复制的链接带 `source=web_explore_feed`，脚本会自动剥掉 | 支持 `BV`/`av`/`b23.tv` 短链，无需 token | 只认 `/episode/<id>` 单集链接；`/podcast/<id>` 是整档频道，会提示用户改发单集 |
| 内容形态 | 视频（较短） | 视频（长短不一） | 纯音频，单集常 20 分钟–2 小时，文件可达上百 MB，下载/识别也更慢 |

## 前置依赖

- **ffmpeg** — 抽取音频。`brew install ffmpeg`
- **mlx_whisper**（Apple Silicon）— 语音识别。装在 `python3.13` 下：`python3.13 -m pip install -U mlx-whisper`
- **Apple Silicon（arm64）Mac**。脚本会在缺失 mlx_whisper 时自动改用 `python3.13/3.12/3.11` 重跑，所以即使 Homebrew 把默认 `python3` 切到了别的版本也不会断。
- 模型默认 `mlx-community/whisper-large-v3-turbo`（约 1.6 GB，首次下载一次），走 `hf-mirror.com` 镜像；下完离线缓存，每次约 15–60 秒。

## 工作流程

### 1. 运行脚本

```bash
python3 ~/.claude/skills/video-to-text/scripts/transcribe.py "<链接>"
```

`<链接>` 可以是小红书视频、B站视频、或小宇宙单集（`xiaoyuzhoufm.com/episode/<id>`）链接。

可选参数：`--out-dir <目录>`、`--model <repo>`、`--language auto|zh|en|...`（默认 `auto`，中文内容若自动识别不稳就传 `zh`；小宇宙基本是中文，建议直接传 `zh`）、`--force-asr`（忽略B站字幕、强制语音识别）。

脚本会在 `/tmp/v2t_<id>/` 下产出：

- `raw_text.txt` —— 整段文字（ASR 路径已自动裁掉结尾重复幻觉）
- `segments.txt` —— 带时间戳的逐句：`[起始 -> 结束] 文本`
- `metadata.json` —— 平台、id、标题、作者、简介、时长、来源（字幕/ASR）、模型、耗时（小宇宙还会多出 `show` 节目名、`pub_date` 发布时间）

### 2. 读取输出

Read `raw_text.txt`、`segments.txt`、`metadata.json`。`metadata.json` 的 `source_method` 告诉你这版是 `subtitles`（B站字幕，文字干净）还是 `audio+asr`（语音识别，需要校对）。

### 3. 校对并整理（最重要的判断环节）

- **B站字幕来源（少见）**：仅当视频带了可下载的 CC/人工字幕（接口 `player/v2` 的 `subtitle.subtitles` 非空）时才会走这条路。注意：B站播放器里那个"AI字幕"开关生成的是客户端实时字幕，**不在接口里**（实测 `need_login_subtitle:false` 但列表为空），脚本拿不到，会自动回退到 ASR。所以 B站绝大多数视频都是 ASR 来源。
- **ASR 来源**：在中文口播、医学科普/行业术语、人名上必然有错字，**必须**对照上下文校对。脚本已用标题+简介作 `initial_prompt` 偏置，但只能减少、不能消除错误。重点修这几类：
  - **同音/近音术语错字**：按上下文还原。如 落蛋白→酪蛋白、水减→水解、胺基酸→氨基酸、容解→溶解、低质→低脂、粘膜→黏膜、遵医主→遵医嘱、生白针→升白针、褶糖→蔗糖、过度→过渡、血口→缺口 等。
  - **人名/机构名/品牌**：以 `metadata.json` 的 `author`（小宇宙里即节目名 `show`）为准，别信 ASR 同音转写；小宇宙的 `desc`（shownotes）常列出嘉宾、章节、书名等，可对照还原专有名词。
  - **播客来源（小宇宙）**：主播口齿通常比短视频清晰、错字更少，但仍要留意嘉宾名、品牌名、书名、中英夹杂；开场自我介绍和结尾"下期预告/广告"处的名字最易错。单集往往较长（半小时以上），按"开场寒暄→主体章节→结尾"分段，shownotes 的章节顺序是好线索。
  - **断句与标点**：原文多为逗号连缀，按语义重新分句、加句号/问号，拆自然段。
  - **结构性分段**：口播常有"首先/其次/最后总结"等线索，据此加小标题、列表。
  - **含糊处**：个别句子音频含糊、识别不可靠时，按上下文合理还原，并可在文末注明该处为推断。
  - **语言**：B站内容可能是英文等其它语言（`auto` 会自动识别），按实际语言整理，别强行翻成中文。

### 4. 写出最终文件

把校对后的文字稿写成 Markdown，放到**当前工作目录**，文件名 `<标题>-文字稿.md`（标题取自 metadata，去掉非法字符 `/ : * ? " < > |`）。模板：

```markdown
# <标题> — 视频文字稿

**来源**：<小红书/B站 视频 | 小宇宙播客>（<BV号/笔记ID/单集eid>：<id>）
**作者**：<author>（小宇宙即节目名；若已知主播/嘉宾可补上）
**时长**：<duration>秒
**说明**：本内容无内嵌字幕（小宇宙同理；或：本稿取自B站字幕）。文字稿由……语音识别转写，并校对了术语与错字，仅供参考。

---

<按语义分段的正文，必要时带小标题/列表>
```

完成后告诉用户文件路径，并说明：这是机器转写+人工校对、非内容自带字幕（除非用了B站字幕）；如需带时间戳的逐句版（`segments.txt`）或换更高精度模型重跑，可再提。

## 失败场景与处理

脚本内置了鲁棒性处理，通常无需介入：
- **小红书自动剥参数**：自动去掉 `source=web_explore_feed`/`m_source`（否则返回信息流首页而非该笔记数据），并保留必需的 `xsec_token`。
- **小红书失败重试**：XHS 偶尔返回降级页面，会间隔重试最多 4 次。
- **python 版本自适应**：mlx_whisper 缺失时自动改用 python3.13/3.12/3.11 重跑。
- **小宇宙**：单集音频是公网 CDN 直链，无需登录/签名，稳定；长单集会自动放宽下载超时（最长 20 分钟）。

退出码：
- **2**：图文笔记/非视频、或小宇宙**频道**链接（`/podcast/`，是一整档而非单集）—— 没有单一口播音频。让用户发某一期的 `/episode/` 链接。
- **3**：小红书重试 4 次仍取不到笔记 —— 基本是 `xsec_token` 过期。让用户在浏览器重新打开笔记，复制**完整链接（含 xsec_token）**再发。小宇宙上则意味着单集已下架/私密/被删。
- **4**：取不到可播放的音视频流。B站常见于地区/会员限制；小红书常见于链接失效；小宇宙常见于**付费/会员专享单集**（公网取不到音频）。让用户换条公开链接。
- **5**：缺 ffmpeg 或 mlx_whisper，按提示安装。
- **6**：不是小红书、B站、也不是小宇宙的链接。

## 不要做的事

- 不要把 `raw_text.txt` 原样交差 —— 那是带错字的半成品（B站字幕来源除外）。
- 不要为"忠实"保留 ASR 明显错字；校对是为了正确和可读。
- 不要改脚本里固化好的解析/下载/ASR 逻辑，除非遇到新的页面/接口变化。
